Ottimizzatore HTML v1.1

ha lo scopo di ridurre lo spazio occupato dal codice della pagina HTML eliminando caratteri e tag inutili. Mediamente si riesce a guadagnare circa il 10% e ciò significa che il codice della pagina risulterà il 10% più veloce da caricare e quindi ridurre anche il volume di traffico.In alcune circostanze il guadagno di spazio puo' arrivare e superare anche il 30%.

Naturalmente si sta parlando solo del codice HTML e non delle immagini o di altri oggetti inclusi nella pagina che influiscono in modo massiccio sul tempo di caricamento.
Su un numero considerevole di pagine HTML l'ottimizzazione può far risparmiare lo spazio locale e lo spazio web il quale tende sempre ad esaurirsi.
Un altro vantaggio dell'ottimizzazione è quello di rendere difficoltosa la lettura del sorgente della pagina web. Infatti con l'ottimizzazione vengono eliminati i return, gli spazi e tutto risulterà attaccato. È disponibile una breve guida on line per essere subito operativi.

TuTToInUno InsTaller v1.1

Non è un programma per creare pacchetti di installazione ma è un tool per realizzare pacchetti di installazione composti da un unico file eseguibile partendo da un pacchetto di installazione già esistente ma composto da più file.
Se si desidera distribuire le proprie applicazioni via Internet è sicuramente più comodo distribuirle in un unico file senza dover ricorrere agli archivi Zip (o archivi simili).

L'archivio Zip oggi è supportato in modo nativo da Windows ME e Windows XP ma tali Sistemi Operativi hanno il difetto di far navigare l'utente nel file zip come se esplorasse una normale cartella. La differenza con la normale cartella è che l'applicazione eseguita ha come cartella di lavoro la cartella temporanea e non quella in cui risiede l'eseguibile. Di conseguenza, l'utente meno esperto potrebbe non riuscire ad installare l'applicazione in quanto il setup non trova gli altri file.
Per tal motivo, se si desidera che il proprio programma abbia una maggiore diffusione, bisogna evitare di perdere questi utenti e pertanto occorrerà fornire loro un pacchetto di installazione composto da un unico file. Purtroppo il Wizard "Autocomposione Installazione" di Visual Basic crea pacchetti di installazione composti da più file e per rimediare bisogna utilizzare un programma alternativo.
Un'altra strada è quella di utilizzare TuTToInUno Installer il quale partendo dal pacchetto di installazione realizzato dal Wizard "Autocomposione Installazione" crea un pacchetto di installazione composto da un unico eseguibile.

N.B.
TuTToInUno è stato realizzato per lavorare con pacchetti di installazione creati con l'utilità di Visual Basic e pertanto potrebbe non funzionare con altri pacchetti.
Sicuramente non funziona con quei pacchetti che richiedono il riavvio del Sistema Operativo e che riprendono in modo automatico l'esecuzione dell'installazione.

GiCriptoFile v1.0

Purtroppo l'e-mail non è un mezzo sicuro per inviare documenti riservati. Internet deve essere considerata come una grande ragnatela nella quale ad ogni nodo corrisponde un computer. L'e-mail per raggiungere il destinatario transita per tali nodi. Durante la spedizione l'e-mail può essere intercettata e letta. Se si ha l'esigenza di inviare tramite e-mail documenti riservati e personali e si desidera che nessuno possa accedere a tali informazioni, se non il legittimo destinatario,

una delle soluzioni possibili è quella di cifrare (o crittare) il messaggio. In questo modo la persona che dovesse intercettare il messaggio si troverebbe tra le mani un file illeggibile.
GiCriptoFile è appunto un programma che consente di cifrare il documento originale in modo da ottenere un file illeggibile e quindi protetto da occhi indiscreti. Solo il destinatario, in possesso della chiave segreta (password) e del programma in questione, potrà decodificare il messaggio.
GiCriptoFile utilizza un algoritmo di crittazione proprietario a chiave simmetrica a 128 bit e può codificare qualsiasi tipo di file e di qualsiasi grandezza: documenti, filmati, musica, immagini, eseguibili, ecc..
Inoltre GiCriptoFile è progettato per fornire una password d'accesso a programmi non forniti di tale funzionalità.

GI Editor RSS v1.0.0

L'RSS è l'acronimo di Really Simple Syndication . I Feed RSS rappresentano un innovativo mezzo per fruire dei contenuti Internet. Infatti, tramite i file RSS forniti dai siti Web e tramite appositi programmi detti 'Aggregatori', l'utente può visualizzare immediatamente brevi descrizioni sulle novità di centinaia di siti web in pochi istanti.

In questo modo potrà individuare velocemente le notizie di suo interesse e accedere direttamente alle pagine web contenenti tali notizie.
Tale servizio risulta pertanto molto utile se offerto da siti web di informazione. Cosa sono in realtà i Feed RSS? Sono semplicemente dei file formattati secondo determinate specifiche basate su XML. Questi file conterranno i titoli di ciascun contenuto, una breve descrizione e l'url della relativa pagina web contenente il contenuto. Il sito web che vuole fornire tale servizio deve realizzare un file secondo tali specifiche e aggiornarlo ogni volta che sono presenti novità nel sito web sostituendo il file xml ogni qualvolta (lasciando l'url di tale file invariato).
GI Editor RSS permette di realizzare in modo semplice ed intuitivo i file contenenti i Feed RSS. Pertanto tale programma è rivolto soprattutto ai gestori di Siti Web che vogliono offrire ai loro visitatori questo potente ed innovativo servizio.
